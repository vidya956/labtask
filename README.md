# labtask

This repository contains a simple portfolio project and a Java-based student result management project.

## Projects included

- Portfolio website
  - HTML and CSS based personal portfolio
  - Files: `portfolio/index.html`, `portfolio/css/style.css`

- Student Result CI project
  - Java Maven project for result calculation and testing
  - Files: `student-result-ci/`

## Technologies used

- HTML
- CSS
- Java
- Maven
- JUnit 5

## Run the Java project

```bash
cd student-result-ci
mvn test
```

## Run the portfolio

Open `portfolio/index.html` in a browser.
